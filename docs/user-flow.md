# FoodSafe Supplier Query Management

## User Flow

QA Manager
→ Dashboard
→ Supplier List
→ Select Supplier
→ Raise New Query
→ Select Category
→ Enter Question
→ Set Priority and Due Date
→ Submit Query
→ Query Status
→ Supplier Response
→ QA Review
→ Mark Resolved

1. Supplier List
2. Raise New Query
