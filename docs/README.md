# FoodSafe Supplier Query Management

Full-stack supplier food safety query management system.

## Frontend

React + Vite + React Router + Lucide Icons

## Backend

Java + Spring Boot + Spring Data JPA

## Database

MySQL

## Main Features

- Supplier dashboard
- Supplier list
- Search suppliers
- Raise food safety query
- Query categories
- Priority
- Due date
- Query status
- Query timeline
- Mark query as resolved
